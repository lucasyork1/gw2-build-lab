# Code of Conduct

## Our standard

Be respectful, specific, and evidence-minded. Debate builds and data without attacking players. Welcome contributors of different skill levels, regions, languages, identities, and play styles. Do not harass, threaten, discriminate, publish private information, spam, or manipulate reviews.

## Enforcement

Repository maintainers may edit or remove contributions and restrict participation when behavior harms the community. Report conduct concerns privately through the repository owner’s GitHub profile contact channel rather than posting sensitive details in a public Issue. Maintainers should handle reports discreetly, consistently, and without retaliation.

## Scope

This standard applies in repository spaces and when someone publicly represents this project.
